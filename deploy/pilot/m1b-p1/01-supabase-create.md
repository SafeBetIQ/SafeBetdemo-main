# Phase 1 — Create the Supabase Pilot project (owner action)

**Not AWS. The provisioner role has no Supabase authority.** You perform this with a Supabase management token
for org `fhttwsuoliasybqkacrm`, held only in your shell. Never share the token, DB password, or service-role key
with Claude or commit them.

## Inputs (set in THIS shell only)
```powershell
$env:SUPABASE_ACCESS_TOKEN = '<your management token>'   # never commit / never echo
$PilotDbPassword = Read-Host -AsSecureString 'Pilot DB password'   # strong, generated by you
```

## Create (Management API) — or use the dashboard with identical values
- Organisation: `fhttwsuoliasybqkacrm`
- Name: `SafeBet IQ Pilot`
- Region: `eu-west-1`
- Plan: `pro`  ·  then enable **PITR** add-on on the new project
- DB password: `$PilotDbPassword`

```powershell
$body = @{ organization_id='fhttwsuoliasybqkacrm'; name='SafeBet IQ Pilot'; region='eu-west-1';
           plan='pro'; db_pass=(New-Object pscredential 'x',$PilotDbPassword).GetNetworkCredential().Password } | ConvertTo-Json
$proj = Invoke-RestMethod -Method POST -Uri 'https://api.supabase.com/v1/projects' `
  -Headers @{ Authorization = "Bearer $env:SUPABASE_ACCESS_TOKEN" } -ContentType 'application/json' -Body $body
# Record $proj.id (the 20-char project ref). Do NOT print tokens/passwords.
```
Then enable PITR on the project in the dashboard (Database → Backups → Point-in-Time Recovery), or via the
Management API add-on endpoint, and confirm `pro` + PITR active.

## Record (feed Phase 1b `01-record-values.ps1`)
- `PILOT_PROJECT_REF`  = the 20-char ref (e.g. `$proj.id`)
- `NEXT_PUBLIC_SUPABASE_URL` = `https://<ref>.supabase.co`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` = the project's anon/public key
- `PILOT_DB_URL` = `postgresql://postgres:<password>@db.<ref>.supabase.co:5432/postgres?sslmode=require`
  (or the Supavisor pooler form `postgres.<ref>` — SSL required). **Secret — goes only into the GitHub `pilot`
  environment in Phase 3, never into a file, never to Claude.**
- The **service-role key** is NOT used in M1B-P1 and must NEVER be a build-time/public variable.

## Firewall
The ref must be a brand-new project in org `fhttwsuoliasybqkacrm`. It must NOT be
`ilibvipqbkugqkppzdmh` (Prod), `uexdjngogzunjxkpxwll` (Demo), or `druuskabkgyotslcgnys` (Guardian).

## Rollback
Delete the project: `Invoke-RestMethod -Method DELETE -Uri "https://api.supabase.com/v1/projects/<ref>" -Headers @{Authorization="Bearer $env:SUPABASE_ACCESS_TOKEN"}` (irreversible; the Pilot is empty/no real data).
